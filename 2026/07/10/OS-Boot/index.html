OS Boot

发表于2026-07-10|更新于2026-08-28|Operating System
|总字数:886

操作系统内核最初保存在磁盘上。通电时，RAM 中还没有可供 CPU 执行的操作系统代码。CPU 复位后从硬件规定的地址开始取指，执行映射到该地址的 BIOS ROM。BIOS 完成硬件自检，再按照启动顺序选择设备。

BIOS 能识别启动设备并读取磁盘扇区，但它不负责解析文件系统、按路径查找内核。它先从磁盘的固定位置装入一小段代码；这段代码再找到能力更强的后续程序，直到某一级能够解析文件系统并装入内核。

这个由小程序逐级装入大程序的过程称为自举。

磁盘布局

分区时写入分区表，格式化在分区中建立文件系统，安装操作系统时再写入引导程序、内核和系统文件。开机前，后续各级程序已经位于磁盘上的约定位置或文件系统中。

整块磁盘的第一个扇区不属于某个普通文件，它保存少量引导代码和分区表，称为主引导记录（Master Boot Record，MBR）。MBR 是整块磁盘的入口：它根据分区表找到应该继续启动的分区。

每个分区也有自己的第一个扇区，其中可以保存该分区的引导代码。活动分区中的这段记录称为分区引导记录（Partition Boot Record，PBR）。PBR 是分区内部的入口：它继续寻找位于文件系统中的启动程序。更大的启动程序、内核映像和系统文件都作为文件保存在分区中。

MBR 属于整块磁盘，PBR 属于具体分区。保存这些固定入口的扇区称为引导块；能够沿着这条引导链启动系统的磁盘称为启动磁盘或系统磁盘。

磁盘级引导

MBR 占 512 字节，内部同时保存引导代码和分区信息：

范围 大小 内容
前部 446 字节 MBR 引导代码
中部 64 字节 4 个分区表项，每项 16 字节
末尾 2 字节 启动签名 0x55AA

BIOS 将 MBR 读入 RAM；在典型的 x86 机器中，装入位置是物理地址 0x7C00。确认启动签名后，BIOS 跳转到该地址，CPU 开始执行 RAM 中的 MBR 副本。

446 字节不足以容纳文件系统解析和内核加载逻辑。MBR 引导代码只需检查自身携带的分区表，找到活动分区，再读取该分区的第一个扇区。如果启动签名无效、没有活动分区或后续扇区无法读取，引导链就在这里中断。

分区级引导

MBR 将活动分区的 PBR 装入 RAM 并跳转执行。PBR 中的代码继续装入更大的启动程序，使引导过程从磁盘级进入分区级。

启动程序能够解析分区中的文件系统，找到内核映像、启动配置和必要的初始化数据，将它们装入 RAM，准备启动参数，最后跳转到内核入口。

内核接管

内核开始执行后，引导程序的任务结束。内核建立中断与异常处理入口，初始化内存管理、进程管理和设备驱动，挂载根文件系统，再启动第一个用户态服务或登录程序。此后，普通程序通过系统调用请求内核服务。
