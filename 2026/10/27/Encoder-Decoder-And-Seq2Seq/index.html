Encoder Decoder And Seq2Seq

发表于2026-10-27|更新于2026-10-28|Natural Language Processing
|总字数:1.1k

从单值输出到序列输出

循环网络可以把末状态接分类头，输出一个类别；也可以在每个输入位置接任务头，给出对齐的标签。机器翻译需要一条输出序列，长度与顺序都可能与源句不同，因此需要独立的生成过程。

输入与输出都是序列的任务，称为序列到序列（sequence-to-sequence，简称 Seq2Seq）。输出需要一条独立的时间轴，长度与每个位置的内容由模型逐步决定。

编码器与解码器

经典实现把网络拆成两半：编码器读入整条源序列，把内容压成一个固定维度的向量 ；解码器从 出发，一次生成一个目标 token，并把已生成的前缀作为下一步输入，递推关系写作：

是源句长度， 是编码器的末状态， 是解码器状态。 是解码器的循环单元，先把输入 token 查嵌入表变成向量，再与 一起更新状态。 是输出层权重，把状态映射成词表大小的得分，softmax 把这些得分变成概率分布 。两半各有独立参数，只通过 连接。

生成与训练

生成：从 BOS 到 EOS

生成从起始符号 <bos> 开始，到结束符号 <eos> 停止：

  1. 编码器读入整条源句得到 ，用 初始化解码器状态；
  2. 把 <bos> 作为第一个输入，得到第一个位置的概率分布，取一个 token 作为 ；
  3. 把 作为下一步输入，状态随之更新，得到 ；
  4. 重复第 3 步，直到输出 <eos> 或达到长度上限。

示例采用贪心策略：每一步取概率最大的 token。生成在输出 <eos> 或达到长度上限时停止。

训练：错开一位的输入与标签

训练时目标句已知。把目标句整体错开一位，前一位作解码器输入，后一位作监督标签。目标句为“学生 喜欢 深度 学习”时：

解码器输入 <bos> 学生 喜欢 深度 学习
监督标签 学生 喜欢 深度 学习 <eos>

每个位置学的是同一件事：给定此前的真实 token，预测下一个。真实前缀来自标注数据，与模型上一步输出无关，这种训练方式称为教师强制（teacher forcing）。

损失是逐位置的交叉熵，位置 的损失为 ，对有效位置求和或取平均后反向传播。

PAD 与损失

批量训练时短句要补齐到同一长度，补位符号记作 <pad>。补齐位置不是真实目标，计算损失时需要屏蔽，否则模型会把填充当成要预测的内容。

训练与推理的差别

同一句话在两种模式下逐位置的输入并不相同：

!../assets/seq2seq-teacher-forcing.svg

训练时解码器收到的是标注里的前一个目标 token；推理时收到的是模型上一步的输出。生成错一个 token 会改变下一步的输入，错误因此可能影响后续输出。

固定上下文模型的局限

串行计算

编码器与解码器都按时间步推进， 依赖 ，同一句内部无法并行，序列越长单步等待越多。教师强制把整段前缀一次送入，也不改变状态更新的顺序。

固定上下文

源句越长，压进同一个 的信息越多，翻译与摘要的质量越容易下降。门控让信息更容易穿过时间链，却没有取消只交出一个向量这一步。

输入反转

一个工程技巧是把源句反过来送入编码器。源句开头的词因此在编码器最后几步才被读入，与解码器最先要生成的词在时间上更接近，但固定的上下文维度不变。

下一步的改法是保留编码器的每个位置，让解码器每步按当前状态重新分配读取比例，即注意力。
