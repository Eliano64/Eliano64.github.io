Deep Learning Training Pipeline

发表于2026-10-26|更新于2026-10-27|Deep Learning
|总字数:2.6k

下面用监督学习的例子说明一次训练里发生了什么：有标签、有可导的损失、用反向传播求梯度、用优化器更新参数。强化学习与无监督预训练也常使用同一个前向、损失、反向、更新的骨架，差别在数据来源与目标函数。

从输入到预测

训练流程的起点是数据形状与任务形式，这两者决定结构的选择：输入是展平的像素、卷积特征图还是序列，输出是类别、概率还是实数。下面的前向描述以最简单的全连接层为例。

图像是像素张量，可以直接进入线性层或卷积层；文本是词编号，需要先经过嵌入查表变成向量，再做矩阵运算。第一层把输入线性组合，再过激活函数，得到一组新的数值；下一层在这组新数值上重复同样的操作。层数加深，表示从低层模式逐步组合成高层语义。

以图像识别为例，靠前的层常对应边缘与纹理，靠后的层对应部件与物体。换成文本或表格，层次结构并不相同，所以“逐层抽象成边缘、部件、物体”是图像模型的典型情形，不是所有网络都如此。

训练流程的组成

先把配置与循环分开，避免把静态设置当成训练步骤。

配置阶段确定：数据划分、模型结构、损失函数、优化器与学习率、是否加归一化、是否加正则化（用于抑制过拟合，例如权重衰减、Dropout）、是否做学习率调度与早停。这些都是启动训练前要定下来的选择。

循环阶段只有四件事反复执行：前向、算损失、反向、更新。归一化层与 Dropout 属于模型结构的一部分，在前向里生效，不在更新之后单独执行。Dropout 在训练时按概率把部分激活置零，以减少模型对特定单元组合的依赖；归一化中哪些元素一起计算均值和方差，以及训练与推理的差异，见 Batch-Norm-And-Layer-Norm。

  1. 划分数据：训练集用于更新参数，验证集用于选择超参数与早停，测试集用于最终报告。数据较少时，先保留独立测试集，再在其余数据上交叉验证，轮换各折的训练与验证角色以选择超参数。
  2. 确定结构：层数、每层宽度、激活函数、归一化与 Dropout 的位置。
  3. 初始化参数：权重按某种分布随机初始化，偏置通常置零，尺度的推导见 Weight-Initialization-And-Variance。
  4. 前向传播：将一个 batch 的数据输入网络，得到预测。
  5. 计算损失：把输出与标签的差距变成一个标量。
  6. 反向传播：算出损失对每个参数的梯度。
  7. 更新参数：优化器按梯度改参数，学习率决定步长。

正则化、调度、早停是可选项，是否采用取决于过拟合程度与训练预算。把可选项当成必选项会增加不必要的复杂度；必需项缺失时训练无法进行。

输出层与模块顺序

分类任务把未归一化的 logits 交给 CrossEntropyLoss 或 BCEWithLogitsLoss，由损失函数内部完成 log_softmax 或 sigmoid。只有在推理或需要展示概率时，才显式套 softmax 或 sigmoid。无约束回归在输出层不加压缩，直接给出实数；目标有确定范围时可以缩放。

模块顺序同理不是固定公式。常见写法是 Linear → BatchNorm → ReLU → Dropout：归一化放在线性层之后、激活之前，Dropout 放在激活之后。这是组合示例，并非所有网络都遵守：残差网络常把归一化放在卷积之前，Transformer 的前馈层是 Linear → GELU → Linear。

判断顺序是否合理，要看三点：哪些元素一起计算均值和方差，激活是否改变尺度，残差连接（把某层输入直接加到该层输出上）相加的两路是否同尺度。

epoch、iteration 与 batch

batch 是一次前向与反向里的一组样本，batch size 是这一组的样本数。处理一个 batch 算一次循环迭代，通常对应一次优化器更新；使用梯度累积时，处理若干 batch 才更新一次。

参数量也不等于显存占用。激活值随 batch、空间尺寸与序列长度增长。数值精度同样影响占用：fp32 是 32 位浮点格式，bf16 是 bfloat16，一种 16 位浮点格式；同样数量的数分别占 4 字节与 2 字节。Adam 还为每个参数保存两份矩估计。

验证与早停

训练集上的损失下降不代表模型变好，可能只是记住了训练样本。验证集用来观察泛化，即模型在未见数据上的表现：验证损失开始上升而训练损失还在下降，是过拟合的信号。

早停的做法是保存验证损失最低那一轮的参数，而不是最后一轮的参数。测试集只用于报告最终指标，用测试集反复挑模型，等于把测试集变成了验证集。

损失曲线短期上升是正常现象，小批量梯度带有噪声；判断趋势要看一段窗口内的平均，不要逐点比较。准确率不连续、不可导，只作观察指标，优化器优化的始终是损失。
