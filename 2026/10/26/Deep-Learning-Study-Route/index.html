深度学习在机器学习中的位置

深度学习是机器学习的一个分支。模型仍是参数化的函数，训练仍是定义损失、求梯度、沿负梯度更新参数。与线性模型的区别在函数形式：多层可微变换复合起来，特征表示与分类器一起从数据中学出。把深度学习当成一组框架 API 的集合，就看不到这条主线。

表示学习与特征工程的分工

传统机器学习里，特征通常由人设计，模型在这些特征上做分类或回归。深度学习把“从原始输入构造表示”这一步也纳入学习。以图像为例，靠前的层常对应边缘与局部纹理，中间的层组合出部件，靠后的层组合出物体。

这种从数据中学出的表示称为表示学习。表示学习并不总占优势：结构化表格数据上，人工特征配合中小规模模型往往更合适。优势出现在原始输入维度高、标注数据足够多、结构具有明显层次性的场景。

训练过程中仍有大量人工决策，包括数据清洗与增广、网络结构、损失函数、正则化强度。数据划分、结构、损失函数与正则化都属于训练前的人工配置，不会通过训练自动得到。

学习路线

学习顺序分为四步，顺序本身比速度重要。

  1. 先掌握机器学习的基本概念：训练集与测试集、损失函数、过拟合、评价指标。
  2. 再理解神经网络的训练流程：前向、损失、反向、更新如何组成一个循环。
  3. 用到什么数学就补什么数学：矩阵形状对不上时补线性代数，看不懂导数连乘时补链式法则。
  4. 用 PyTorch 把前面的内容落到代码上，完成一次训练循环并检查输出。

当下的工程实践会影响时间分配：样板代码已经可以借助工具生成，看懂代码、选择方法、分析训练结果因此比记住 API 更重要。

训练循环的七步

下面以“有标签、有可导损失、用反向传播求梯度、用优化器更新参数”的神经网络为例，这个循环可以拆成七步。

  1. 定义模型结构：确定有几层、每层多少个单元、用什么激活函数。
  2. 初始化参数：给权重一个初始值。
  3. 前向传播：输入数据，逐层算到输出，得到预测。
  4. 计算损失：用损失函数把预测与真实标签的差距变成一个数。
  5. 反向传播：用链式法则算出损失对每个参数的梯度。
  6. 更新参数：按负梯度方向执行一次参数更新，步长由学习率决定。学习率过小则收敛慢，过大则可能越过极小值来回震荡，具体分析见 Backpropagation-Chain-Rule。
  7. 重复：回到第 3 步，直到达到停止条件。

第 2 步与第 6 步决定训练能否收敛。初始化尺度不当，信号会在层间放大到溢出或压缩到零；学习率不当，损失会震荡甚至发散。
