感知机

感知机的结构

一个感知机对输入做加权求和，再加偏置，最后通过阈值函数输出 0 或 1。这里的阈值函数指阶跃函数：自变量不小于 0 时取 1，否则取 0。

所以感知机是一个线性分类器，决策边界是 这个超平面；输入为二维时，超平面退化为一条直线。

感知机的特点在于参数由误差反馈调整：分类错误时按下节规则修改权重，正确时保持不变。

学习规则与收敛条件

严格线性可分指存在一个超平面，使两类样本分别落在平面两侧，且没有样本落在平面上。当数据有限、满足严格线性可分、学习率为固定正数、样本反复遍历时，感知机的误分类次数有上界，会在有限次更新后停止；数据不满足线性可分时，上述收敛结论不成立。

学习规则只调整一个超平面的位置与方向：权重决定法向量，偏置决定偏移量。每一类错误样本都使平面沿修正方向移动一个与学习率成正比的量，因此这套规则能做的，是在给定表示下寻找一个把两类分开的超平面。

MLP

多层感知机（Multi-Layer Perceptron，MLP）在输入与输出之间加入隐藏层，隐藏层做仿射变换和非线性激活，输出层再按任务给出结果。

突破局限的办法是改变表示：用隐藏层把输入映射到一组新坐标，让两类在新坐标里线性可分，输出层再画一个平面。

是“或”， 是“与非”。再对 与 做一次加权判定：

逐点验证：
(0, 0) 0 1 1 0
(1, 0) 1 1 2 1
(0, 1) 1 1 2 1
(1, 1) 1 0 1 0
![隐藏层表示：四个样本与一条分界 602](/assets/dl-xor-hidden.svg)

例子里隐藏层把输入映射到新坐标，输出层在新坐标里给出一个超平面；本例的构造使用阶跃函数。

当隐藏层的映射是非线性时，输出层的超平面回到原始输入空间后可以成为非线性边界，由若干段拼成，从而分开单层分不开的点。若隐藏层整体退化为仿射映射，边界仍是一条直线。

层数越多，“换表示、再划分”重复的次数越多，边界能拼出的形状也越复杂。

多个单元能拼出什么

单个感知机只负责一次线性判定：加权和过阈值，输出 0 或 1。输出层把这些取值加权求和再判定，等于对若干个判定做逻辑组合。

“与”要求同时满足，对应区域是几个半空间的交集，形状是凸的；“或”只要有一块满足，对应区域是并集，一般不是凸的。所以“多个感知机可以围出一个区域”只在特定组合下成立，不保证得到凸区域。

层数与单元数越多，能拼出的划分越复杂，但复杂度由结构与权重共同决定，不能只按层数估计。

无论串多少层，都可以合并成一次矩阵乘法。整体仍是一次仿射映射，只是可表示的映射受中间层宽度限制，其秩不超过最窄一层的宽度（秩是矩阵中线性无关行或列的最大数目）。

层数本身不带来非线性。深度的意义来自层与层之间的非线性，仿射串联没有这种能力。这只说明仿射串联的退化，不代表没有非线性就无法训练：退化影响表达能力，训练是否成功是优化问题。

表达能力与可训练性

万能逼近定理给出一个结论。在紧集上，用一个足够宽的单隐藏层网络，激活函数取连续 sigmoidal 函数，输出层取线性组合，能以任意精度一致逼近任意连续函数（Cybenko）。这里的 sigmoidal 指两端极限分别为 0 与 1 的连续函数。

这条定理有明确前提：激活函数要满足该定理要求的性质，多项式激活不在保证之内；宽度可以任意大；结论只涉及存在性。

万能逼近定理不保证梯度下降能找到这组参数，也不保证泛化。参数由随机初始化后经优化器搜索得到，能否完成训练取决于初始化尺度、激活函数的梯度行为、归一化与学习率。
