集成学习的思路

决策树给出的是一串可以直接读出的规则：年龄大于 30，收入低于 5000，就分到这一类。规则可读，代价是对具体样本过分敏感。训练集里少一个样本，或者某个特征取值稍微变动，整棵树的结构就可能改变。

集成学习不试图把单棵树做得更稳，而是承认单棵树会出错，让许多棵各自不完美的树共同给出预测。这条路上有两条分支：让树彼此独立地生长，最后汇总结果，代表是随机森林；让树一棵接一棵地修正前一轮的误差，代表是梯度提升树。

为什么需要集成

单棵树的脆弱

决策树的划分准则与剪枝在 Decision-Tree 里已经写过，这里只看一个后果：结构不稳定。深层树为了把训练集分到几乎纯净，在每个节点上找当前最优切分，而“当前最优”往往由少量样本决定。

具体一点：某连续特征上的候选阈值，左侧区间里只落着两个样本。删掉其中一个，这个阈值就失去意义，分裂点移到下一段空隙；父节点选中的特征可能因此从“收入”变成“年龄”，下面的整棵子树随之重排。

这种波动在统计上叫方差：换一批训练数据，模型的预测跟着变多少。与方差并列的是偏差：模型的假设与真实规律差多远，换数据也不会消失。深树把训练集记得很牢，偏差小、方差大。

单棵树调超参数时，偏差与方差之间存在权衡。把树调浅，偏差上升；把树调深，方差上升；换超参数只是在这一权衡上移动。集成换了一个做法：不去寻找偏差与方差都小的单棵树，而是构造许多棵各自有误差的树，让误差在汇总时相互抵消一部分。

随机森林的出发点就在这一段：单棵树方差大，就让许多棵方差大的树各自出错，再让这些错误在平均中相互抵消。

从弱学习器到强学习器

集成学习（Ensemble Learning）把多个能力有限的模型组合起来，通常能得到比单个成员更好的泛化性能，但不保证对每一个成员都更优。弱学习器通常指表现优于随机猜测、但预测能力有限的模型。集成也可以组合能力较强的成员；强学习器指组合之后达到可用精度的模型。

多个独立判断按多数意见合成，是理解集成的一个类比：单个判断可能出错，但出错方向分散时，多数意见更接近正确。这个类比有一个前提：合成有效的原因在于各成员的误差彼此偏离，而不是成员数量本身。

平均为什么能压低方差

假设 个成员的预测误差近似独立、量级相当，取平均之后，误差方差降到单个成员的约 。方差下降，偏差基本不动，因为每个成员都朝同一个真实规律逼近，平均不会把系统性偏离抵消掉。

前提里的“独立”是薄弱环节。实际成员之间存在相关性：高度相关时，各成员在相同样本上一起出错，平均几乎不起作用。相关性越高，能摊掉的方差越少，收益上限由成员之间的差异决定。下面两种随机性正是为了压低这种相关性。

由此可以看出成员该选多强。成员本身偏差大时，平均只是把一个偏得厉害的答案重复多次，误差不会自动消失。随机森林因此使用生长到接近纯净的深树：单棵树的方差由平均摊薄，单棵树的偏差由深度压小。

随机森林

森林由大量决策树组成，每棵树都是逐层切分的 IF-THEN 结构。如果所有树都用同一份数据、同一批特征训练，投票就失去意义，因为每棵树会给出接近相同的答案。随机性保证每棵树看到的样本与特征不同。

双重随机性

第一层是样本随机。Bootstrap 是有放回抽样：训练集有 个样本，每次训练一棵树时，从原数据集中随机有放回地抽 个，组成这棵树专属的训练子集。有放回意味着同一个样本可能被抽中多次，也可能一次都不出现。

第二层是特征随机，也叫特征子空间（Random Subspace）。在树的每个节点做分裂时，先随机抽出一个子集，通常取 个，只在这个子集里找最优切分，全部 个特征不参与比较。没有这一步，所有树在每个节点上看的是同一批候选特征。

两层随机是叠加的：样本不同，每个节点能选的特征也不同，树与树之间的相关性被压低。前面“平均能摊掉多少方差”的结论能否兑现，取决于这一步的效果。

袋外样本提供了一份无需额外划分的验证集，减少单独划分验证集或执行交叉验证的开销。对某个样本来说，森林里总有一部分树没见过该样本；用这些树单独预测，就得到一次未使用该样本自身信息的检验；把所有样本的这类检验汇总，就是袋外误差。OOB 误差可用于比较超参数，但最终报告仍应在独立的测试集上做一次评估。

这份验证集有边界：只存在于使用 Bootstrap 抽样的模型里，因为只有这类模型才有“未见过某个样本”的树。换到 Boosting，每棵树都在全量数据上训练，袋外估计无从构造。

特征重要性

森林训练完成后可以直接给出每个特征的贡献度，用来判断哪些因素在起作用、哪些特征可以舍弃。做法有两种。MDI 基于不纯度减少：不纯度是节点内标签的混杂程度；MDI 统计一个特征在所有节点上带来的不纯度减少量，按节点样本数占全树的比重加权，再跨树平均。这种算法计算快，但偏好取值多的高基数特征，连续特征与 ID 列的候选切分点较多，容易得到偏高的分数。

Permutation 基于排列：把一个特征的值随机打乱，观察模型性能下降多少，下降越多说明该特征越重要。Permutation 不受特征取值基数影响，结论更可靠。特征重要性反映模型对特征的依赖程度，不构成因果关系。

适用范围与代价

随机森林的优点集中在实现成本上。

  • 抗过拟合能力较强：大量深树的平均降低了方差；在极端噪声或样本极少时，随机森林仍可能过拟合。
  • 预处理需求低：对单调变换不敏感，不需要归一化；缺失值与类别特征仍需按库的要求处理。
  • 高维数据可用：成千上万个特征也能训练，不必先做显式降维。
  • 附带特征重要性：可直接输出特征贡献度，便于业务归因。
  • 支持并行：树的生成彼此独立，可以充分利用多核 CPU。

随机森林未必是精度最高的模型，但常作为首个基线的候选。

三条局限也明确。可解释性下降：单棵树的判断路径清楚，成百上千棵组合起来就难以直观解释。计算与内存开销大：保存大量树结构占用内存，预测时每条数据要经过所有树，速度低于单棵树。参数与实现细节仍需调整：树的数量、节点候选特征数都影响效果。

Bagging 与 Boosting

集成学习有两大主流思想，目标相同，路径不同。Bagging 用 Bootstrap 造出多份训练集，并行训练彼此独立的模型，再投票或平均；Boosting 串行训练，每棵新树专注前面树尚未拟合好的部分，最后把预测累加。

Bagging：并行投票

每棵树拿到一份有放回抽样得到的训练集，节点上还随机选特征，学到不同的视角；训练完成后汇总所有树的预测。树与树之间没有依赖，可以同时训练。这条路线的目标是压低方差。

Boosting：串行纠错

树一棵接一棵地训练，后一棵只能在前一棵的结果之上工作。每棵新树的目标是前面模型尚未拟合好的部分，这一目标由负梯度给出，负梯度的计算仍依赖原始标签。以平方损失为例，负梯度就是真实值与当前模型预测之差，记为 。

两条路线压低的对象不同。Bagging 的成员各自拟合原目标，平均之后方差降下来，偏差基本不变；Boosting 每一轮直接针对尚未拟合的部分，偏差逐轮减小，同时也会影响方差。前者改善稳定性，后者改善拟合能力。

更新方式

左列的更新在 Gradient-Descent 里已经写过：参数沿负梯度更新一步。GBDT 做的是同一件事，只是更新的对象变成了整个模型，而“沿这个方向更新一步”的具体形式就是加上一棵新树。

成员树要浅

每棵树都不宜生长过深。单棵深树偏差小、方差大，可修正的空间有限，再叠加只会把训练集里的噪声一起累加；需要逐轮减小的是偏差，所以成员使用浅树（偏差较大、方差较小），每棵只学一小部分尚未拟合的结构。

适用范围与代价

GBDT 在表格数据上精度表现稳定，竞赛与业务场景里都常见。GBDT 能同时处理数值型与类别型特征，训练完自带特征重要性，对单调特征变换不敏感，不需要标准化；缺失值与类别编码仍需按具体实现处理。损失函数也可以按业务目标选择。

代价有五个，都与串行结构有关。

  • 训练速度较慢：轮次之间依次依赖，难以并行生成多棵树；单棵树内部仍可并行计算。
  • 容易过拟合：数据量少、噪声大时需要仔细调参。
  • 对超参数敏感：学习率、树的数量、树的深度都要调节。
  • 不擅长超高维稀疏数据：文本的 one-hot 编码是典型的不利场景。
  • 类别特征处理不够原生：经典 GBDT 需要手工编码。

三大工业实现

三次改造各有侧重：XGBoost 改造目标函数与工程效率，LightGBM 改造训练速度，CatBoost 改造类别特征与目标泄漏。

XGBoost

XGBoost（eXtreme Gradient Boosting）的第一项改动是正则化：在目标函数里显式加入树复杂度的惩罚项，一项罚叶节点数量，一项对叶节点权重施加 L2 惩罚。

第二项改动是使用二阶梯度。经典 GBDT 只用一阶梯度决定方向与大小，XGBoost 同时使用二阶信息，相当于在选分裂点时额外考虑损失曲面的弯曲程度，分裂点通常更准。

第三项是工程优化：列采样、缓存感知访问、核外计算，这些手段合起来使单机处理上亿样本成为可能。此外 XGBoost 内置正则化与 Early Stopping，验证集指标不再改善时停止加树，训练过程更可控。

LightGBM

LightGBM 的侧重点是训练速度。大数据集上，训练速度通常明显高于按特征逐点遍历的实现。

第一项改动是直方图算法。XGBoost 的精确贪心模式对每个特征遍历候选切分点，LightGBM 先把连续的浮点特征分段，装进离散的桶里，形成直方图；找分裂点时只遍历这些桶，不必再看每个样本的取值。候选切分搜索的计算量和特征存储开销因此下降。XGBoost 也提供直方图模式，具体行为取决于配置和实现。

第二项是带深度限制的 Leaf-wise 生长。传统决策树按层生长（Level-wise），一层没长满不会进入下一层；Leaf-wise 每次只挑一个叶子继续分裂，优先选择分裂增益最大的叶子。这样长出来的树在相同叶子数下通常更深。

第三项是两件提速工具：单边梯度采样（GOSS）只对梯度小的一部分样本抽样，梯度大的样本全部保留；互斥特征捆绑（EFB）把很少同时取非零值的特征合并成一列，减少实际参与计算的特征数。

CatBoost

CatBoost（Category Boosting）针对类别特征设计。在类别型特征特别多的业务场景里，CatBoost 减少了手工编码的工作量。

第一项改动是原生支持类别特征。XGBoost 可使用独热编码，也支持启用原生类别处理；CatBoost 可以直接接收原始类别，内部用目标统计量（Target Statistics）完成映射。

第二项是排序提升。GBDT 家族有一个隐患叫预测偏移：算某个样本的类别统计量时，把该样本自身的标签也算了进去，标签于是泄漏进特征，模型在训练集上偏乐观。CatBoost 用有序目标统计量（Ordered Target Statistics）按数据顺序只用排在前面样本的标签构造统计量，避免同一行的标签进入自身特征。排序提升（Ordered Boosting）则针对梯度估计的偏差，两者针对不同环节。

第三项是对称树结构。CatBoost 的常用默认设置生成对称树：同一层使用同一个分裂条件，推理时可以整层批量计算，预测速度通常高于非对称树；这一结构属于默认配置，并非所有配置都强制使用。

怎么选

表只能给三个具体场景，背后的依据是数据规模与特征类型。样本量大到单机训练时间成为瓶颈时，直方图与 Leaf-wise 的收益最大。类别特征占多数时，手工编码的成本可能高于换框架。

先试哪一个

三个框架的共同点比差异更值得记住：基学习器（每轮单独训练的那棵树）都是决策树，模型都是加法模型，训练目标都是把损失逐轮降低。选型要看团队已有的生态与部署条件，也要看类别特征的处理成本：类别列多且不想手工编码时，原生支持类别特征的实现更省工作量。

路线尚未确定时，可以先用随机森林建立基线：预处理需求低，短时间内就能给出特征重要性与一个可用的精度，再决定是否换成 Boosting。GBDT 系列的精度通常更高，但对超参数更敏感，调参成本也更高。
