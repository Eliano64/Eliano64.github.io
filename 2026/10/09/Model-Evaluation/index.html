Model Evaluation

发表于2026-10-09|更新于2026-10-27|Artificial Intelligence
|总字数:7.6k

在比较模型性能之前，先要有一个基线模型作为比较的参照系。基线模型（Baseline）指第一个快速实现、结构相对简单但流程完整的模型：数据怎么读、怎么划分、指标怎么算都已经能完整执行，只把模型的表达力压到最低。基线的价值不在精度，而在建立参照系。

训练模型为的是让模型抓住数据背后的规律，从而对从未见过的新数据也给出准确预测，这种能力叫泛化能力。测试集只是“没见过的新数据”的一次抽样，测试集给出的数字既是性能的估计，也带着抽样本身的偶然性。

评估基准与回归指标

评估在测试集上完成，指标算的是预测值与真实值之间的差距。本节只处理回归任务。分类任务关心的是混淆矩阵、精确率、召回率、F1、ROC 与 AUC，那套指标的前提是预测输出为类别或概率，放在 逻辑回归 里讲。

Baseline 的作用

基线模型的构造原则是取最简单、又能把整个流程做完的那一个：回归任务直接预测训练集的均值，或者用 线性回归 这类最简单的模型。基线同时充当三样东西。基本参照：指标明显差于基线时，应检查实现、特征、复杂度与数据划分，不能仅凭这个结果认定实现有 bug。改动效果的参照：每次调参、换特征带来的收益都相对基线计算。数据侧的问题定位：连基线都表现异常，问题往往在标签或特征上，这时该回到 数据预处理 检查，而不是换更复杂的模型。

平均绝对误差（MAE）

MAE（平均绝对误差）把每个样本的偏差取绝对值再求平均。 是样本数， 是真实值， 是预测值：

MAE 的单位与目标变量完全一致，数字可以直接读成“平均差了几万元”。绝对值的惩罚随偏差线性增长，个别极端样本的影响比在平方项下小得多，所以 MAE 对异常值的敏感度低于 MSE；极端样本仍会拉高 MAE，只是权重小得多。代价是绝对值在零点不可导，把 MAE 当作损失函数来优化不如平方项方便，零点可以用次梯度，主流框架的 L1 损失默认就这样处理。

均方误差（MSE）

MSE（均方误差）先对偏差取平方，再求平均：

平方把大误差的影响显著放大：偏差翻一倍，惩罚变成四倍。这正好适合对大偏差零容忍的场景，医疗与自动驾驶就是一例，一次大错不能和几次小错等价看待。代价是单位被平方（例如“平方万元”），失去了直观的业务含义。好处是处处可导，作为损失函数最方便优化。

均方根误差（RMSE）

RMSE（均方根误差）对 MSE 开根号，把量纲还原成目标变量的单位，同时保留平方项对大误差的惩罚：

单位可解释与惩罚大误差这两件事同时成立，所以在工程实践和数据科学竞赛（例如 Kaggle）里，RMSE 是常用的回归指标。

决定系数（R2）

R2（决定系数）换了一个基准：拿模型误差与“直接输出评估集均值”的误差相比。式中的 是评估集上真实值的均值，也就是最朴素的预测水平：

R2 衡量模型消除了总方差中多大比例的不确定性。等于 1 表示预测完全正确；等于 0 表示与直接输出均值一样；取负值表示比输出均值还差，上界为 1，下界没有限制。标签为常量时，分母中的总方差为 0，公式不适用。R2 是无量纲的，比较的是同一份数据上模型相对均值预测强多少；换一个数据集，总方差本身变了，两边的数值不能直接比较。

指标之间的分工

四个指标回答的不是同一个问题，选哪个取决于误差分布的特征和业务对可解释性的要求：

指标 单位 对大误差的敏感度 作为损失函数的可导性 适用场合
MAE 与目标变量一致 较低，惩罚随偏差线性增长，极端值仍会拉高指标，权重小于平方项 零点不可导，可用次梯度训练 异常值较多，或需要直接解释平均偏差
MSE 目标变量单位的平方 高，惩罚随偏差平方增长 处处可导 作为训练损失，或对大偏差零容忍
RMSE 与目标变量一致 高，继承平方项 由 MSE 开方得到，训练时在 MSE 上求导更方便 既要可解释又要惩罚大误差，常用选择
R2 无量纲 通过分子中的平方项体现 通常作为报告指标 同一数据集内比较模型与均值预测的强弱；换数据集后总方差不同，数值不可直接比较

报告指标与训练损失的分工

上表的可导性一列不是装饰。训练时梯度要从损失回传到参数，参与训练的量必须提供可用的梯度。MSE 处处可导，梯度里只含偏差的一次项，因此占住了损失函数的位置。MAE 在零点不可导，次梯度就能让训练继续，不要求处处可导。R2 基本不参与训练：无量纲让报告方便，但只有落在同一份数据、同一套预处理上，两个 R2 才能直接比较。

于是同一个实验里出现两套数字是正常的：用 MSE 训练，用 MAE 或 RMSE 报告。前者提供光滑的梯度，后者提供业务能读懂的量。这也解释了为什么 RMSE 在报告里出现得最多：RMSE 的单位与目标变量一致，读者不需要在脑子里开方。

比较还有一个前提：两个数字必须来自同一份测试集、同一套预处理。换一次划分、改一次归一化，指标就不可比，此时算出来的“提升”可能只是流程差异。

残差诊断

指标是全局汇总，只说平均错了多少，不说错在哪。残差（residual）是逐样本的偏差，定义为真实值减预测值：

逐样本看残差，才能看出误差是否带有结构。理想情况下残差应当接近纯噪声：与预测值无关、均值为零、近似对称。

评估的稳定性

指标选对之后，还要问这个数字换一次数据划分会变多少。变幅小，说明模型对数据划分不敏感；变幅大，说明评估结果对具体划分较敏感。

单次划分的问题

最常见的做法是一次 train/test split：把数据分成训练集与测试集，训练集用来拟合参数，测试集只用来算指标。问题在于这一次划分的结果依赖运气。测试集只含有限个样本，恰好抽到几个极端样本，RMSE 就整体偏高；换一个随机种子重新划分，同一个模型会给出差别不小的数字。

于是单次划分下两个模型相差很小的指标并不能说明谁更好，差异可能完全来自样本的落位。样本量越小，这种抖动越明显。这也是先有基线再谈改进的原因：改动必须稳定地超过基线，而不是在运气好的那一次划分上超过基线。

K-Fold 交叉验证

K-Fold（K 折交叉验证）把划分重复多次再汇总：把数据均匀分成 K 份，每一轮取 1 份留作验证、其余 K-1 份用于训练，重复 K 轮，每个样本恰好被验证一次。留出的那一份在这里叫验证折：真正只用一次的测试集仍留到最后。

最终报告 K 次评估结果的均值和标准差。均值是对泛化性能的估计，标准差衡量这个估计有多依赖具体划分。标准差大，说明模型对数据的组成敏感，单次数字不能当结论；标准差小，两次实验之间的差异才可能真的来自模型本身。

均值和标准差要一起看。如果两个模型的均值只差一点点，而这点差距还落在各自的标准差范围里，就不能宣称改进，需要更多轮重复或者更多数据才能分辨。代价是要训练 K 次。K 越大，每一折用到的训练集越大，但更多折不保证估计更稳：各折模型彼此高度相似，折间差异随之变小，多折带来的信息增量有限，所以 K 要在训练成本与估计质量之间权衡。

同一批数据既选参又报分，数字会偏乐观

同一套划分还能用来选超参数，例如正则化的系数：在 K 轮里比较不同取值的均值，选出最好的那个；选完之后，测试集再报告一次。如果把选超参数和报告全部放在同一批数据上，连一个独立的测试集都不留，报出来的数字就会偏乐观。

欠拟合与过拟合

评估稳定之后，训练误差与验证误差的组合就能说明模型缺什么。训练误差是在训练集上算出的指标，验证误差是在留出的验证集上算出的同一指标。只看其中任何一个都会误判。

欠拟合

欠拟合（underfitting）指模型过于简单，没有充分学到训练数据中的规律：训练误差与验证误差都很高，且两者差距不大。差距不大说明模型并没有在训练集上偷偷记住什么，只是没有能力表达数据里的结构。这时增加数据通常帮助有限：容量不足时，两条曲线会一起停在同样高的水平上，更多样本只是把这个水平估得更准。这不等于数据毫无用处，数据多了才撑得起更大的模型，但仅靠加数据解决不了容量不足。

过拟合

过拟合（overfitting）指模型过于复杂，除了真实规律，还把噪声一并记住了。噪声指数据中与目标无关的随机波动。表现是训练误差极低、验证误差明显更高，两者差距大。这时增加数据可能有帮助：更多样本让同一份噪声在总量里被稀释，模型难以把噪声逐一记住。

学习曲线

学习曲线以训练样本量为横轴，两条曲线分别是训练误差与验证误差。训练误差通常低于验证误差，因为模型在训练集上见过样本，误差自然更小。学习曲线的作用是把上面两个判据从两个点扩展成一条趋势来看。

横轴也可以换成训练轮数，用来观察同一训练过程随迭代推进的变化。两条曲线的形状与读法随横轴改变，需要与样本量曲线区分。

三种形态都以样本量为横轴。

欠拟合的曲线：两条曲线都停在偏高的位置，彼此靠近，随样本量增加几乎水平，加样本不会把两条曲线拉下来，该做的是提高模型表达力。

良好拟合的曲线：两条曲线都处在较低的水平，验证曲线紧贴训练曲线上方，间隙小且稳定，继续加样本收益递减。

过拟合的曲线：训练曲线保持很低，随样本量增加可能略微上升，验证曲线从高处降下来，同一份样本量下两线间隙明显，容量越大间隙越宽。间隙随样本量增加而收窄，说明加数据有效；间隙不随样本量收窄、只随容量扩大，说明该压容量。

横轴的两种画法回答两个不同问题。以样本量为横轴，问的是数据够不够：两条曲线在右侧是否已经合拢。以训练轮数为横轴，问的是该练多久：验证曲线先降后升，最低点就是该停的位置，这也是早停（验证指标开始变差就停下来）这条规则能成立的前提。轮数轴上那段上升与数据量无关，不能读成“样本不够”。

欠拟合的对策

欠拟合要做加法，三个方向都在提高模型的表达力：

  • 特征工程：加多项式特征的高次项，做特征交叉组合多个特征，用对数、指数等数学变换，或者结合业务知识补领域特征。
  • 增加训练轮数：加大 epochs，给模型更多学习时间，直到损失不再下降。
  • 增加模型复杂度：从 线性回归 换成 决策树、随机森林这类模型，也就是换到 集成学习 的方向。

过拟合的对策

过拟合要做减法，让模型别太极端。可动的方向有四个：增加训练数据，降低模型复杂度（减少多项式阶数或树的深度），做特征选择（主动去掉无关与冗余特征，减少干扰信号），以及正则化。前三者的效果依赖数据本身是否够多、哪些特征该留，正则化最通用，因为不换数据也不换模型，只在训练过程中限制有效容量。具体做法按作用面分成五类，下面逐一展开。

这四个方向不是同一回事。增加数据改变的是信息量，样本里的噪声被平均掉，模型看到的是更接近真实规律的分布。降低复杂度与特征选择是主动放弃一部分表达力。正则化可以保留参数结构，通过约束参数或训练过程限制有效复杂度。有代表性的训练数据可以帮助减少过拟合。数据获取成本高时，可以优先评估降低复杂度、特征选择和正则化，也可以组合使用。

正则化

正则化（regularization）指在训练目标、参数更新、网络结构、训练流程或训练数据上追加约束，限制模型的有效容量，用略高的训练误差换取泛化性能。没有正则化的时候，模型为了迎合噪声会剧烈扭曲参数，拟合出一条穿过每个训练点的曲线；加上约束之后，参数被压回平滑的形态。约束的强度由超参数控制，代价是最优的训练误差略微变高，期望换来更低的验证误差。这个交换并不保证成立，强度选得过大，训练误差与验证误差会一起升高。

约束可以加在五个位置：损失函数、参数更新、网络结构、训练流程、训练数据。前两个直接作用于权重的数值，后三个改变模型看到的计算图或数据分布。

权重为什么要小

在特征表示与网络结构固定时，权重幅度会影响输出对输入变化的敏感程度。过大的权重可能放大输入扰动，使模型更容易拟合噪声。限制权重幅度可约束这种敏感性，但实际效果仍取决于模型结构与数据。

这也是正则化与降复杂度能互相替代的原因：两者都在降低有效容量。区别是降复杂度直接拿掉参数（少几阶多项式、少几层树），正则化保留全部参数但限制参数的取值范围。

为什么深度网络默认 L2

深度网络的泛化依赖参数之间的协同作用与权重的平滑分布，而不是剔除某几个特定神经元，所以均匀缩小的 L2 与这种工作方式合拍，L1 制造的稀疏反而会打散这种协同。更实际的理由是可导性：L2 项的导数是 ，处处光滑，对 SGD（随机梯度下降）、Adam 这类基于梯度的优化器都友好；L1 在零点不可导，需要额外处理。

把 L2 写进损失，惩罚项会先混进梯度，再连同梯度一起混进一阶动量 （梯度的滑动平均）与二阶动量 ：

于是 不再是一个统一的强度。梯度本来就小的参数 极小，自适应除以 时，正则化力度被放大；梯度本来就大的参数 极大，同样的除法把正则化力度压缩。原本设定的衰减强度被这套自适应缩放改变，得到的更新式与直接做权重衰减不同。这不等于 L2 在 Adam 下失效：损失里加了 L2 项，训练照样会把权重压小，只是惩罚力度随参数的梯度量级变化，无法像解耦衰减那样按 精确控制。

AdamW 把权重衰减从自适应缩放里解耦出来： 与 只由原始损失的梯度计算，权重衰减直接作用在参数上，与梯度的自适应缩放分开：

网络结构上：Dropout

Dropout（随机失活）换了一个作用对象：不压权重数值，而是改网络结构。具体做法是每次前向传播时，以概率 随机把一部分神经元的输出置 0，也就是在这一次训练里关闭这些神经元，而且每次关闭的神经元都不同。

这个动作带来两个后果。其一，神经元不能再依赖某个特定邻居的输出，每个位置都必须学出独立有用的特征。其二，每个 batch 训练的都是一个不同的子网络，推理时相当于成千上万个共享参数的子网络在集体投票，这是一种隐式集成。

训练时部分神经元不工作，剩余神经元的输出期望会被压低。为了让训练与推理的期望一致，需要反向 Dropout（inverted dropout）：训练阶段在丢弃的同时，把存活神经元的输出除以 ， 取 0.5 时存活的激活值被放大成原来的 2 倍。推理阶段所有神经元正常工作，输出保持原样，不做任何缩放调整。

Dropout 率取决于层的位置和具体任务，常见起点有：隐藏层 0.5，让每次前向保留的神经元组合尽量多样。输入层若要用，取 0.1 到 0.2，避免丢掉过多原始输入信息。Transformer 0.1 左右，Transformer 本身的结构设计已经比较合理，过重的 Dropout 会妨碍大规模预训练。这些数字是候选值，不是各层的统一默认。卷积网络同样可以用 Dropout，只是卷积特征图在空间上高度局部相关。随机丢单个位置带来的信息扰动有限。实践中常把 Dropout 放在全连接层或池化层之后，并与批归一化（BatchNorm）配合使用。BatchNorm 不能替代 Dropout：BatchNorm 归一化激活的分布，让训练更稳定，正则效果只是副产品；Dropout 显式随机关闭神经元，改变的是每个 batch 的网络结构。

这些取值背后是同一个参数的两端。 越大，每次前向能用的神经元越少，容量被压得越狠，过头就是欠拟合，训练损失迟迟不降； 越小，子网络彼此太像，集成效应消失，等于没加。同一层该取多少，仍然要靠训练与验证两条曲线来判断。

训练流程上：早停

早停（early stopping）把正则化做在时间轴上。过拟合表现为验证指标在某个时刻开始恶化，那就在恶化之前停下来：监控验证集指标，连续若干个 epoch 没有改善就终止训练，并回退到表现最好的那个 checkpoint。

允许连续多少个 epoch 没有改善，由 patience 控制，通常 5 到 20 是合理范围：取小了，会在指标的正常波动里误停；取大了，等于等到过拟合已经发生之后才停。

回退到最好的那一份权重

停止时回退到表现最好的那个 checkpoint，而不是直接用最后一轮的权重，原因是恶化本身就有滞后：能确认指标在变差的时候，权重已经离开最优点好几步了。

早停算正则化，理由是隐式约束：没有修改损失，也没有改动结构，但训练步数越少，权重离初始值越近，可探索的参数空间越小，等价于限制了模型的有效复杂度，这一层作用常被称为隐式正则化。

早停的前提是手里有一份验证集。这份数据可以参与选超参数与决定何时停，但不能用来拟合权重：一旦用验证集更新参数，监控到的指标就不再代表“没见过的数据”。验证集也不能充当最终报告的测试集，否则报告的数字会偏乐观。

训练数据上：数据增强

数据增强（data augmentation）换到数据侧。前面几种方法都在限制模型容量，数据增强扩大训练分布：对训练数据施加随机变换，让模型难以记住具体样本，被迫学习更通用的特征。图像任务里常用的变换有翻转（水平、垂直）、裁剪（RandomCrop）、小角度随机旋转、颜色抖动（亮度、对比度）。同一张图换几个角度和亮度，相当于在不额外标注的情况下多了几倍训练样本，因此在计算机视觉任务上效果尤其显著。

这些变换必须保住标签：翻转和裁剪不能把目标切掉，颜色抖动不能改变类别。变换后的样本标签错了，等于往训练集里注入噪声。

数据增强的代价比较特别：训练准确率可能下降。训练分布被撑开之后，模型连训练集都不再容易拟合到接近零误差，而验证集准确率反而可能更高。这个反差说明训练准确率不是目标：变换后的样本在参数空间里把决策边界推到了更稳的位置，代价是模型更难只靠记住个别样本达到低训练误差。降低训练准确率的机制不止数据增强一种，强正则化、过大的 Dropout 率、容量不足的模型都会让训练准确率下降，区别在于动机：数据增强在保留信息的前提下扩大分布，其余几种是在压缩容量。

按作用面归类

五种做法落在五个不同的位置，看清位置比记住名词更有用：

方法 作用位置 核心思路
L1 与 L2 正则化 损失函数 惩罚大权重，限制参数幅度；L1 压出稀疏权重并顺带做特征选择，L2 均匀缩小全部权重
权重衰减 参数更新 每步把权重向零衰减；在 AdamW 中与自适应缩放解耦，避免 被梯度量级扭曲
Dropout 网络结构 随机关闭神经元，迫使特征冗余，每个 batch 训练一个子网络
早停 训练流程 验证指标恶化时终止训练，用训练步数限制可探索的参数空间
数据增强 训练数据 增加数据多样性，减少记忆个例，代价是训练准确率可能下降

工业流水线的组合用法

实际训练一个深度网络时很少只挑一种。现代工业级训练流水线往往同时应用 AdamW 权重衰减、适度 Dropout、丰富的数据增强与早停机制：权重衰减约束参数幅度，Dropout 约束单次前向的通路，数据增强扩大训练分布，早停控制训练时长。四种方法的作用面不同，但组合起来并不保证互不冲突；叠加之后剩下的那部分容量才是模型真正用来拟合规律的部分。
