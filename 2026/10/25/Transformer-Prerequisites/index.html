Transformer Prerequisites

发表于2026-10-25|更新于2026-11-10|Artificial Intelligence
|总字数:4.3k

文本的表示与基本运算

Transformer 先把文本变成向量，再根据上下文更新各位置的表示。理解这一过程，需要明确数据怎样排列、基本运算怎样改变表示，以及序列中的信息如何汇总。

公式统一采用行向量：一个 Token 对应一行，多个位置按行排列。

1. 标量、向量、矩阵与张量

标量是一个数，向量是一组有序数值，矩阵按行和列组织数值。在深度学习中，张量通常指多维数组，标量、向量和矩阵分别是零阶、一阶和二阶张量。

模型处理的离散文本单位称为 Token（词元），可以是词、子词或字符。分词（tokenization）按照分词器的规则切分文本，再为每个 Token 分配词表编号。一个自然语言词可能拆成多个 Token，因此模型的序列长度按 Token 数量计算。

编号还需转换为向量，才能参与后续运算。一个 Token 的向量包含 个数，长度为 的序列因此组成 的矩阵。这里的 是表示维数，也常记为 。

把 条序列组成一个批次，并用补位符号 <pad> 补齐到相同长度 ，得到形状为 的三阶张量。三个方向分别对应样本、位置和特征。

补齐使序列能够统一计算，但补位不属于真实文本。注意力不应从这些位置汇总内容，训练损失也不应把补位当成预测目标。具体的屏蔽方式在 Softmax 一节说明。

阶数与维数

三阶张量表示有三个索引方向；一个 Token 的表示有 512 维，则表示该向量有 512 个分量。两种说法中的“维”含义不同。PyTorch 用 Tensor 统一表示这些数组。

3. Embedding

Token 是离散符号，编号只表示词表中的位置。编号 8 与编号 9 相邻，不代表对应的 Token 在意义上接近，因此不能把编号大小直接当作语义特征。

例如词表有 50,000 个 Token、，单个 Token 的 one-hot 表示需要 50,000 个分量，Embedding 则输出 512 个分量。查表与 one-hot 向量乘嵌入矩阵等价，但实现时无需构造整条 one-hot 向量。

训练损失会更新嵌入矩阵，使向量适应预测任务。语义关系可能表现为相近方向或相似偏移，但不保证每种关系都能用向量加减表达。编号、one-hot 与词向量的区别见 词的表示问题。

Embedding 提供初始表示，后续序列层再结合上下文更新表示。同一个 Token 在不同上下文中的最终表示因此可以不同。

查表得到的向量只取决于 Token 编号，不包含出现位置。模型还需要位置信息来区分序列顺序。一种常见做法是为每个位置构造一个向量，再与该位置的 Token 嵌入相加；两个向量必须同形状。顺序信息为何需要单独提供，见 位置信息。

单个位置的特征变换

Embedding 把符号变成向量，但输入向量还需要根据任务重新组合特征。线性层改变表示，激活函数引入非线性，两者组成前馈网络。

FFN 的输出形状与后面的 残差连接 有关。

序列的输入、输出与信息汇总

逐位置变换能处理每个 Token 的特征，但翻译等任务还需要组织输入与输出序列，并决定输出当前位置应利用哪些输入信息。

7. Encoder 与 Decoder

Encoder（编码器）把输入变成适合后续任务使用的表示；Decoder（解码器）根据这些表示和已有的输出，产生目标结果。两者描述的是计算分工，不限定必须使用循环网络或注意力。

在带注意力的序列模型中，编码器可以保留每个输入位置的表示，组成矩阵 。解码器生成目标序列时，按当前需求利用这些表示，不必只接收一个固定的汇总向量。

例如翻译时，编码器处理源句，解码器根据源句表示和已经生成的目标前缀预测后续 Token。逐步生成的过程见 从 BOS 到 EOS 的生成过程。

8. Seq2Seq

Seq2Seq 是序列到序列（Sequence-to-Sequence）：输入与输出都是序列，但长度和顺序不必对应。Encoder-Decoder 描述一种结构分工，Seq2Seq 描述任务形式，两者不能直接等同。

例如，输入“桌子 底下 有 一只 猫”包含 5 个 Token，输出“There is a cat under the table”按示例划分包含 7 个 Token。“桌子底下”对应的内容还出现在输出后部，因此翻译需要重新组织信息，不能逐个替换输入 Token。

自回归生成以起始符号 <bos> 为条件预测第一个 Token，再把已经生成的前缀用于下一次预测，直到生成 <eos> 或达到长度上限。训练时目标序列已知，可以用真实前缀作为输入；这与推理时使用模型生成的前缀不同。

经典循环 Seq2Seq 把整条输入压缩为固定维度的上下文向量 ，长序列的信息容易受到压缩限制。注意力保留各输入位置，再为不同输出位置计算不同的汇总结果，从而减轻对单个固定向量的依赖。

掩码与负无穷

掩码（mask）标记哪些位置允许参与计算。注意力中，补位位置的分数在 Softmax 前设为 。由于 ，这些位置的权重为 0，便不会参与后续加权汇总。每一行至少要有一个有效位置，才能正常归一化。

注意力权重与词表概率

注意力中的候选是序列位置，权重用于汇总这些位置的表示。输出层对词表 Token 给出的原始分数称为 logits，Softmax 将这些分数转换成下一 Token 的预测分布。两处使用同一运算，解释对象不同；注意力权重高不等于对应词即将被生成。

深层网络中的残差与归一化

Attention 汇总位置之间的信息，FFN 变换各位置的特征。反复堆叠这两类子层时，还需要让原输入能够直接参与后续计算，并控制表示的数值尺度。

Transformer 层的组成

文本经过分词和 Embedding 后得到向量序列，位置信息补充顺序。在 Transformer 层中，注意力汇总不同位置的内容，FFN 再对各位置的表示做非线性变换。

以编码器的一层（Transformer block）为例，自注意力与 FFN 构成两个子层。注意力子层通过输出投影匹配输入维数。两个子层分别配有残差连接和 LayerNorm。残差使输入直接参与输出，归一化控制数值尺度，两者帮助这些子层反复堆叠。

将这样的层堆叠 次，上一层的输出成为下一层的输入，序列表示便得到逐层更新。Encoder-Decoder 结构中的解码器还包含读取编码器输出的注意力子层，承担源序列与目标序列之间的信息传递。
